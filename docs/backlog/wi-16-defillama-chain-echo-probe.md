# Сверить эхо-поле `chain` у вендора по всем покрытым сетям

> **✅ ВЫПОЛНЕНО 2026-07-28. Расхождений нет: 274/274, все HTTP 200, 75.5 с.**

**Источник:** adversarial-цикл 3 TASK-007, `critic-logic` L-5.

## Зачем это заводилось

`normalizeDexVolume` отвергает документ, у которого поле `chain` не совпадает с именем
`vendors.defillama`, которое мы отправили. До зонда это допущение опиралось на **две** сети
(`Ethereum`, `Litecoin`), а сама колонка `vendors.defillama` заполнялась из **другого** эндпоинта
(`/v2/chains`).

Риск был конкретный: в списке вендора есть близнецы по отображаемому имени — `Plume`/`Plume Mainnet`,
`SX Network`/`SX Rollup`, `DefiChain`/`DeFiChain EVM`, `Doge`/`Dogechain`. Если бы DEX-эндпоинт
канонизировал одну половину пары в другую, эта сеть ломалась бы **навсегда**, и ломалась бы дорого:
отказ `normalize()` → негативный кэш → `CapabilityUnavailableError`, чьё документированное значение
для агента — «повтори». Агент, варьирующий `days`, обходит негативный кэш вовсе. То есть тихий
бесконечный ретрай.

## Результат

| ---------------------- | --------------------------------------------------- |
| Проверено сетей        | **274** (ровно то, что допускает предикат покрытия) |
| Расхождений эхо        | **0**                                               |
| HTTP-статусы           | 274 × 200                                           |
| Время / конкурентность | 75.5 с / 8                                          |
| Стоимость              | keyless, 0 кредитов                                 |

Все четыре пары близнецов резолвятся **каждая в свою сеть** со своим эхо (`Plume`→`plume`,
`Plume Mainnet`→`plume-mainnet`, и так далее). Сценарий, ради которого зонд и заводился, опровергнут.

## Побочная находка — она закрыла D-1

Пять покрытых сетей отвечают корректным эхо, но нулевым объёмом: `bchyper`, `bsquared`,
`camp-network`, `doge`, `zigchain`. Из них **`doge` возвращает `total24h: null`**.

Это первое **измеренное** подтверждение nullable-агрегатов на **покрытой** сети. До него комментарий
ссылался на `litecoin`, который не покрыт и у которого все пять читаемых ключей на месте — то есть
решение было верным, а цитируемый замер его не подтверждал (`critic-logic` D-1). Комментарии в
адаптере, в туле и в `interfaces.md` теперь ссылаются на зонд.
