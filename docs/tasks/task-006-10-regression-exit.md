## Phase 1 — гейты как тесты `[STUB CREATION]`

1. Тесты падения загрузки реестра: файл отсутствует / битый JSON / дубль `caip2` / алиас-коллизия
   → **исключение на старте**, а не пустой реестр и не отложенная ошибка при первом запросе.
2. Оффлайн-гейт расширен: реестр и `onchain_list_chains` не совершают сетевых вызовов.

## Phase 2 — сведение и объявление `[LOGIC IMPLEMENTATION]`

1. **Полный прогон** обоих пакетов без сети. Зафиксировать фактическое число тестов.
2. **Список изменённых ожиданий** существующих тестов — поимённо, с причиной. Пустой список тоже
   результат; «поправил, чтобы позеленело» без записи здесь — недопустимо.
3. **Changelog объявляет холодную инвалидацию кеша** (OQ-3 подтверждён владельцем): одна холодная
   сессия после выката, migration-скрипт не пишется, протухшие строки уходят штатным TTL.
4. **Scope-guard:** проверить, что ничего из PLAN §5 не просочилось — новых провайдеров нет, `dune`
   не оживлён, рядов chain-TVL нет, автообновления реестра в рантайме нет, dual-read слоя нет,
   валидаторов для `move`/`cosmos`/`utxo` нет.
5. Обновить статусы в `TASK.md`/`ARCHITECTURE.md`; зафиксировать фактические отклонения
   (как минимум — отклонение по R-58a из 006-9).
