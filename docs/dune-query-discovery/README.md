# Dune: как доставать готовые сложные запросы (и чем их закрыть бесплатно)

Прогон динамических workflow **`dune-query-discovery`** + добивка **`dune-query-discovery-gapclose`**:
`repo-audit → discover → profile → adversarial-verify → critic → follow-up → synthesize`.
Вопрос владельца: научить агента доставать агрегирующие ончейн-ответы («сколько BTC добыто»,
«дневной объём DEX по сетям»), которые бесплатный контур `onchain-intel` отвечает отказом, —
переиспользуя тысячи готовых публичных запросов и дашбордов Dune.

**Дата верификации:** 2026-07-27 · **Прогоны:** `wf_af845947-864` (FULL) + `wf_86bdc4b9-bab` (INJECT) ·
**Язык:** ru · **Метрики стоимости:** [run-stats.md](run-stats.md) — канонический источник

## TL;DR — решение

> ### **NARROW-AND-GO.** Полноценный «Dune-слой сложных запросов» в бесплатном контуре не строим. Строим узкий read-only срез Dune — и **сначала разворачиваем бесплатный ярус, который закрывает больше, чем ожидалось.**

**Гипотеза владельца подтвердилась частично, и важно, какой именно частью.**

| Часть гипотезы | Итог |
|---|---|
| «Тысячи готовых запросов можно переиспользовать» | ✅ **читать** результат чужого публичного запроса можно: `GET /api/v1/query/{id}/results`, официально, на Free, 20 кредитов/МБ, исполнение не триггерится |
| «Агента надо научить их искать» | ❌ **программного поиска по чужим запросам не существует.** В официальном MCP тула поиска нет; в OpenAPI 39 путей, единственный search — `POST /v1/datasets/search`, и он ищет **таблицы**, а `GET /v1/queries` возвращает **свои** запросы |
| «Свежесть можно контролировать» | ❌ **на Free — нельзя.** Дословно: «The Free query engine is limited to manual query editor executions only; automated executions (API, scheduling, refreshing) are not available». Протухший результат чужого запроса **нельзя обновить через API ни за какие кредиты** — свежесть целиком во власти владельца запроса |
| «Корректность проверяема» | ✅ да, но **не на Free**: чтение SQL чужого запроса (`GET /api/v1/query/{id}`) гейтится платным планом ⇒ на бесплатном тарифе источник числа **неаудируем** |

**Что оказалось сильнее ожиданий — бесплатный не-Dune ярус.** Добивка **опровергла** вывод
основного прогона «дневной объём DEX не закрывает никто»: `GET https://api.llama.fi/overview/dexs/{chain}`
отдаёт keyless HTTP 200, живьём собрано **10 сетей × 92 дня без единого пропуска**, покрытие 287 сетей,
история с 2016 г. — а адаптер `defillama` и хост в SSRF-allowlist **у нас уже есть**.
Это строка с максимальным fit во всём исследовании (**12/12**) и самая дешёвая интеграция.

**Что оказалось хуже ожиданий.** Flipside — главная бесплатная альтернатива Dune по произвольному
SQL — **мёртв**: NXDOMAIN у API-хоста (подтверждено двумя независимыми DoH-резолверами), домен
редиректит на `edisyl.com`, SDK в архиве. Бесплатной замены Dune по произвольному SQL не существует.

**Условия, при которых NARROW-AND-GO остаётся «go»** (все четыре обязательны):
1. живой зонд с бесплатным ключом подтвердил чтение чужого публичного результата на Free;
2. снят конфликт первоисточника по плановому гейту («Analyst» против «Plus and Enterprise»);
3. расход измерен по `execution_cost_credits`, а не оценён — вендор дословно отказывается публиковать формулу;
4. выставлен `max_credits_per_request` и НЕ выставлен `ignore_max_credits_per_request`.

Если хоть одно не выполнено — вердикт падает в **NO-GO**, и слой замещается бесплатным ярусом.

## Оговорка о надёжности

**По Dune не сделано ни одного живого вызова.** В окружении нет `DUNE_API_KEY`, а заводить аккаунты
агентам запрещено (одна добивка была остановлена ровно на этом). Вся Dune-часть проверена по
документации — и эта документация **четырежды противоречит сама себе** по вопросам, которые решают
всё: плановый гейт Query-эндпоинтов, разрешены ли API-исполнения на Free, цена Small-движка,
движок по умолчанию. Не-Dune ярус, наоборот, проверен живыми keyless-вызовами и потому надёжнее.

`dune.com/pricing` отдаёт краулеру **HTTP 403**, `dune.com/the_defi_report/btc-deep-dive` — тоже 403
(Cloudflare). Ни одно тарифное число нельзя взять со страницы цен; все они — из `docs.dune.com`.

Числа актуальны на **2026-07-27** и дрейфуют. Модель-собранные оценки не проверены живым вызовом.
**Перепроверяйте любое число до того, как потратите деньги.**
