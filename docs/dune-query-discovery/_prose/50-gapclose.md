## 1. Мост «URL дашборда → данные»: `https://dune.com/the_defi_report/btc-deep-dive`

### 1.1. Что документировано

Эндпоинт существует — но не там, где его искал основной прогон. Он есть в **машиночитаемом** первоисточнике `https://api.dune.com/openapi.json` (копия прогона — `aomi_dune.yaml`, 39 путей `[ЖП]`):

```
/v1/dashboards/by-slug/{owner_handle}/{slug}:
  get:
    description: Retrieves the full state of a dashboard using the owner handle and URL slug.
    summary: Get a dashboard by owner handle and slug
    x-required-scope: Read
    parameters: X-Dune-Api-Key (in: header, required: true), owner_handle, slug
    responses: 200 → models.DashboardCrudResponse | 400 | 401 | 403 | 404 | 500
```

В **человеческой** документации его нет: в `docs.dune.com/llms.txt` — 77 записей `api-reference`, слово `dashboard` встречается ровно в одной строке — гайд `https://docs.dune.com/api-reference/apis/quickstart-dashboards.md` (HTTP 200, 17 141 B), и вхождений `by-slug` в нём **0** `[ЖП]`. Гайд — про построение *своих* дашбордов поверх результатов, а не про чтение чужих. Следствие: **плановый гейт для `by-slug` первоисточником не объявлен — `unverified`** (спека даёт только `x-required-scope: Read`, а не план).

### 1.2. Что реально вернёт — и почему это не два шага, а три

`models.DashboardCrudResponse` = `dashboard_id, dashboard_url, is_private, name, slug, tags[], visualization_widgets[], text_widgets[], param_widgets[]` `[ЖП]`.

Ключевой факт, ломающий наивную схему: в `models.VisualizationWidgetOutput` **ровно три поля — `position`, `visualization_id`, `widget_id`. `query_id` там НЕТ.** `query_id` присутствует только в `models.ParamWidgetOutput` (`key, position, query_id, visualization_widget_id, widget_id`), то есть только у виджетов-параметров `[ЖП]`.

Полная цепочка до числа:

| Шаг | Вызов | Что даёт | Гейт |
|---|---|---|---|
| 1 | `GET /api/v1/dashboards/by-slug/the_defi_report/btc-deep-dive` | `visualization_id` каждого графика | ключ обязателен; план `unverified` |
| 2 | `GET /api/v1/visualizations/{visualization_id}` → `models.GetVisualizationResponse` (`created_at, description, id, name, options, query_id, type, updated_at`) | **вот здесь появляется `query_id`** | scope `Read`; план `unverified` |
| 3 | `GET /api/v1/query/{query_id}/results` | само число (кэш последнего исполнения владельца) | 20 кредитов/МБ на Free `[ОП]` |
| 3′ | `GET /api/v1/query/{query_id}` (прочитать SQL = аудит метода) | методология | «Analyst plan or higher» против «Plus and Enterprise» — противоречие первоисточника не снято `[ОП]` |

Цена в вызовах: **1 + N + N** при N визуализациях на дашборде. Метаданных свежести в `DashboardCrudResponse` нет вовсе — только `created_at/updated_at` у визуализации (шаг 2), то есть свежесть *данных* по ответу моста не определяется.

### 1.3. Где обрывается на Free

Нигде не начинается — вход без ключа закрыт целиком. Живые keyless-пробы 2026-07-27 `[ЖП]`:

- `GET https://api.dune.com/api/v1/dashboards/by-slug/the_defi_report/btc-deep-dive` → **HTTP 401**, 27 B, тело `{"error":"invalid API Key"}`;
- то же с мусорным ключом `X-Dune-Api-Key: bogus_test_key` → **HTTP 401**, 27 B, то же тело;
- `GET https://api.dune.com/api/v1/query/1234567/results?limit=1` → **HTTP 401**, 27 B.

Обход через веб-страницу тоже закрыт: `GET https://dune.com/the_defi_report/btc-deep-dive` под desktop-Chrome UA → **HTTP 403**, 5 721 B, `<title>Just a moment...</title>` (Cloudflare-челлендж) `[ЖП]`; в скрэтчпаде прогона зафиксирован тот же ответ (5 571 B, `noindex,nofollow`).

Права на **чужой публичный** дашборд — `unverified`: в спеке для этого пути объявлен 403 со схемой `models.Error403`, пример которой дословно `Not allowed to execute query. Query is archived, unsaved or not enough permissions` `[ЖП]`; без ключа проверить нельзя, а регистрация запрещена заданием.

### 1.4. Вердикт по тезису «тысячи готовых дашбордов можно переиспользовать»

**ОПРОВЕРГНУТ в бесплатном контуре — по четырём независимым замкам:**

1. Keyless-входа нет ни на одном шаге (три HTTP 401), скрейп страницы блокирован Cloudflare (HTTP 403).
2. Даже с ключом мост не отдаёт `query_id` — нужен дополнительный вызов на каждую визуализацию.
3. **Дискавери нет**: чтобы вызвать `by-slug`, надо заранее знать `owner_handle` + `slug`. Поиска чужих запросов/дашбордов в API не существует — единственный search это `POST /v1/datasets/search` (поиск **таблиц**), а `GET /v1/queries` возвращает **свои** запросы `[ОП]`.
4. Аудируемость (прочитать SQL за числом) — платный класс, и связывающий план первоисточником противоречив `[ОП]`.

**Что тезис означает после уточнения:** верно «конкретный чужой дашборд, чей URL мы знаем заранее, можно один раз разложить в `query_id` и закрепить их в конфиге»; неверно «тысячи дашбордов = переиспользуемый корпус». Это ровно та формулировка, которую основной прогон вынес в NARROW-AND-GO — добивка её не смягчает, а ужесточает (добавился шаг 2, которого в плане не было).

**Confidence: high** по механике (спека + 4 живые пробы), **unverified** по плановому гейту `by-slug` и по поведению на чужом публичном дашборде.

## 4. Правило маршрутизации «когда НЕ идти в Dune» (итоговая формулировка)

Правила применяются **в коде** (override поверх любого скоринга), а не в промпте.

- **R1. Ярусное правило.** Если класс вопроса есть в таблице §3 — маршрут идёт на бесплатный адаптер, Dune не рассматривается вовсе. **Новое:** `chain.dex_volume` переезжает из графы «единственное честное основание платить Dune» в бесплатный ярус.
- **R2.** Никогда не маршрутизировать эмиссию/циркуляцию BTC (`chain.supply`) на Dune — закрыто `/stats.totalbc`.
- **R3.** Никогда не маршрутизировать активность сетей Ethereum-экосистемы (`daa`/`txcount`, 27 сетей, история с 2020-01-01) на Dune — закрыто growthepie.
- **R4.** Никогда не маршрутизировать агрегаты DEX / fees / options уровня «протокол · сеть · день» на Dune — закрыто DefiLlama.
- **R5.** Никогда не маршрутизировать точечный факт по адресу/транзакции/токену на EVM — Blockscout `[ОП]`; у Dune такой факт всё равно требует исполнения, то есть дороже по определению.
- **R6. Никакого дискавери через Dune.** Поиска чужих запросов и дашбордов в API нет; мост `by-slug` требует ключа и предзнания `owner_handle`+`slug` (§1). Переиспользование чужой аналитики — **только** по закреплённому в конфиге списку `query_id`, полученному однократно вручную.
- **R7. Идти в Dune только при выполнении (a или b) И (c и d):** (a) нужен произвольный SQL-срез, которого нет ни в одном ярусном эндпоинте — когорты, произвольные джойны, фильтр по контракту/адресу во времени; (b) нужно аудировать чужую методологию, то есть прочитать SQL (платный класс, план `unverified` из-за противоречия Analyst против Plus); (c) выставлен `max_credits_per_request` и НЕ выставлен `ignore_max_credits_per_request`; (d) расход измеряется по `execution_cost_credits` и дельте `POST /v1/usage`, а не оценивается `[ОП]`.
- **R8. Приоритет при конфликте:** бесплатный ярус → (нет покрытия) → **собственный** SQL на Dune. Никогда не «чужой дашборд как источник числа»: его метод непроверяем без платного чтения SQL, а без метода число неаудируемо.
- **R9. Правило подмены определения.** Фолбэк не имеет права молча менять определение метрики (growthepie TVS против DefiLlama TVL). Разные определения — разные capability.
- **R10. Правило незавершённого дня.** Любой дневной ряд ярусного источника перед агрегацией режется до последнего **завершённого** дня (`chart[:-1]`).

## 5. Что осталось незакрытым

### 5.1. Классы вопросов, которые не закрывает ни один бесплатный источник добивки

1. **Произвольный срез с фильтром по адресу/контракту/времени** («активные адреса этого протокола за прошлый вторник», когорты, ретеншн). growthepie — это набор статических файлов: нет SQL, нет параметров запроса вообще; DefiLlama — только преднарезанные агрегаты. Остаётся Dune или собственный индексатор.
2. **Независимая сверка DEX-объёма.** Её нет ни одной. Все три подтверждения §2 — внутри одного документа одного вендора. Класс закрыт **одним** источником с **одной** методологией.
3. **Non-EVM активность** (Solana, Bitcoin, BNB, Avalanche, Tron) в терминах `daa`/`txcount`: в `master.json` growthepie вхождений `bitcoin`/`btc`/`hashrate`/`solana`/`bnb`/`avalanche`/`tron` — **0** `[Д]`.
4. **Майнинг/эмиссия вне BTC.** Вопрос «сколько BTC добыто» закрыт (§3), но у DefiLlama он неотвечаем **ни на каком тарифе**: `/overview/dexs/bitcoin` → 200, но это DEX-объём **на** биткоине (`total24h $285,675` по 5 протоколам), полей supply/issuance/mining ноль; смежный `/emissions` — это анлоки токенов и он платный (402) `[Д]`.
5. **Аудируемость чужой методологии** (прочитать SQL за числом) — платный класс, связывающий план `unverified` `[ОП]`.
6. **Числовые квоты и rate-limit всех трёх источников** — `unverified`: DefiLlama публикует только качественное «Standard/Higher» и не отдаёт `x-ratelimit-*`; growthepie публикует guidance «10 calls per minute», которое **не принуждается** (30 вызовов за ~21 с ≈ 86 req/min, ноль 429) `[Д]`; Blockchain.com документирует «1 every 10 seconds» только для `/q/*` — и это единственный источник, где 429 реально воспроизведена (срыв на 14-м из 20 последовательных, тело `Rate limited`, `retry-after: 0`, бесполезный для backoff) `[Д]`.
7. **Цены платных ярусов там, где они могли бы понадобиться** — `unverified` по обеим сторонам: `growthepie.com/sales` отдаёт боту JS-шелл (46 258 B, ни одной строки с ценой), `defillama.com/pro-api` и `/subscription` → HTTP 403 `[Д]`.

### 5.2. Что это значит для дизайна

1. **По DEX-классу бесплатный ярус — не «второй источник», а единственный.** Значит обязательны: (а) канарейка на внутридокументное расхождение (`breakdown`-сумма против `total24h`) как единственная доступная проверка целостности; (б) локальная копия ответов, чтобы смена политики доступа не обнулила историю.
2. **Все три источника ошибаются в нестандартной форме** — DefiLlama 500 вместо 404, growthepie 403 AccessDenied вместо 404, Blockchain.com HEAD 404 при GET 200. Нужен **per-vendor маппинг ошибок**: иначе «нет такого объекта» будет прочитано как «протух ключ» (лишний фолбэк) или как «упал сервис» (бесконечный ретрай на опечатке в слаге).
3. **Тихая деградация под HTTP 200 — не гипотеза, а факт** (нули и отрицательные комиссии в `/stats`). Валидировать нужно **значения** (знак, диапазон, монотонность), а не только коды. Это худший класс отказа для автоматики и он уже присутствует в ярусе.
4. **Бесплатность — политика, а не контракт.** Фиксировать в конфиге проверенные **пути**, а не хост (`/emissions` уже 402), и держать fallback-провайдера на каждый ярусный класс.
5. **Юридический блокер по Blockchain.com** (ToS §1 против кэша) — либо решение владельца, либо BTC-supply уходит на альтернативу; сейчас строка ярусная, но вне дефолтного маршрута.
6. **Правило незавершённого дня** должно быть общим для всех дневных рядов движка, а не поправкой одного адаптера.

### 5.3. KNOWN LOSSES этой добивки (залогировано, не молча)

- **Клип входа синтеза.** Воркфлоу обрезает поток данных: `clip(…, 70000, 'gap-data')`. До меня дошли **3 строки из 11 кандидатов**; строка Blockchain.com оборвана внутри `subclaims` — её поля `status`, `unverified[]`, `confidence` в мой ввод **не попали**. Статус `CONFIRMED` для неё **выведен** из правила движка (`kill_shot` непустой + `verdict` остался `adopt` ⇒ `refuted = false`), а не прочитан. Полные строки — в `rows`/`table.json` прогона.
- **8 кандидатов не дошли вообще:** Dune `by-slug`, Flipside, BigQuery public, Coin Metrics, mempool.space, Bitquery, The Graph, Token Terminal/Artemis. Разделы 3–5 построены на 3 строках, а не на 11 — **ярус §3 может быть шире, чем показано**; это нижняя граница покрытия, а не исчерпывающий список.
- **§1 достроен не данными добивки, а моими живыми пробами при синтезе** (помечены `[ЖП]`), поскольку профильная строка моста не дошла. Все такие числа приведены вместе с URL/командой и получены keyless, без регистрации.
- **`[ЖП]`-числа отсутствуют в ДАННЫХ ДОБИВКИ** по определению — при сверке отчёта с `table.json` их там не будет; их первоисточник — `api.dune.com/openapi.json`, `docs.dune.com/llms.txt`, `api.llama.fi` и файлы движка `onchain-analytics`.

**Confidence по разделам:** §1 — high по механике, unverified по гейту и правам на чужой дашборд. §2 — high (двойная независимая проба, координаты движка перепроверены). §3 — high по DefiLlama и growthepie, medium по Blockchain.com (строка дошла обрезанной + юридический блокер). §4 — high. §5 — high по перечню дыр, medium по полноте (8 строк не дошли).
