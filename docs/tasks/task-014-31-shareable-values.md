# Задача 014.31: `shareable` со значением на 26 строках манифеста

## Связь со сценариями
- UC-2 — две сессии делят вендорскую квоту

<!-- contract:goal -->

## Цель задачи

Проставить `shareable` на всех 26 строках манифеста способностей с записью вывода и завести код,
применяющий правило. T-014 — первый читатель этого поля.

**Why сейчас.** `ADR-003` D5 ввёл поле, T-012 его объявил, читателя у поля не появилось. Поле без
читателя молча расходится с реальностью.

<!-- contract:changes -->

## Описание изменений

### Изменения в существующих файлах

**Файл `packages/core/src/capability-manifest.ts`:**
- Проставить `shareable` на всех 26 строках
- Рядом с каждым значением — запись, из чего оно выведено

**Файл `packages/mcp-server/src/tools/resolve-capability.ts`:**
- Применить правило: неразделяемый результат не отдаётся из кеша другому принципалу

### Две части задачи с разными зависимостями

| Часть | Предмет | Зависимость |
| :--- | :--- | :--- |
| 1 | значения `shareable` на строках манифеста и гейт счёта строк | нет |
| 2 | применение правила в `resolve-capability.ts` | 014-15 |

**Why разделение записано в задаче.** План предлагает брать её первой при заблокированной сетевой
ветви. Часть 1 в этом порядке выполнима. Часть 2 требует принципала в точке разрешения способности,
а принципал доводится туда задачей 014-15.

### Что значит `shareable`

Результат разделяем, если он не зависит от того, кто спросил. Курс токена разделяем. Ответ,
выведенный из принадлежности кошелька спрашивающему, не разделяем.

### Пропуск значения не собирается

Строка манифеста без `shareable` роняет сборку.

**Why роняет, а не предупреждает.** Умолчание здесь выбирает между утечкой между принципалами и
потерей кеша. Обе стороны стоят дорого, и выбор обязан быть явным.

### Число 26 не зашивается

Гейт считает строки манифеста и сверяет с числом строк, несущих значение. Литерал `26` в коде гейта
не появляется.

**Why.** Докстринг `capability-manifest.ts:117` говорил про 20 строк, пока таблица того же файла
говорила про 26. Зашитое число расходится молча.

## Тест-кейсы

### Модульные тесты
1. **TC-UNIT-01:** `shareable` имеет значение на всех строках манифеста
   - Ожидаемый результат: гейт считает строки, число не зашито (AC-13)
2. **TC-UNIT-02:** строка без `shareable` роняет сборку
3. **TC-UNIT-03** (часть 2, после 014-15)**:** неразделяемый результат не отдаётся из кеша другому
   принципалу
   - Входные данные: запись кеша, положенная первым принципалом; запрос второго принципала
   - Ожидаемый результат: второму принципалу запись из кеша не отдана
4. **TC-UNIT-04** (часть 2, после 014-15)**:** разделяемый результат отдаётся из кеша любому
   принципалу

### Регрессионные тесты
