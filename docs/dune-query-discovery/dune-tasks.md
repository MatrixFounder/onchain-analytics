### Архитектура трека B: гибрид, три слоя

Развилка «проксировать官 MCP / свой REST-адаптер / гибрид» разрешена в пользу **гибрида**, с
жёстким разделением по признаку «тратит ли это кредиты автономно»:

- **Слой A — данные. Наш REST-адаптер `dune`, включён всегда.** Только чтение результата
  закреплённого в каталоге запроса. Идёт через `registry.resolve()` → `safeFetch` → token-bucket →
  `BudgetStore` → кэш. Даёт то, чего официальный MCP дать не может: дешёвое чтение уже посчитанного
  (`GET /query/{id}/results` не триггерит исполнение) плюс наш кэш поверх.
- **Слой B — авторинг. Официальный MCP, по умолчанию ВЫКЛЮЧЕН.**
  `claude mcp add --scope user --transport http dune https://api.dune.com/mcp/v1 --header "x-dune-api-key: <key>"`
  Включает человек на сессию «сочинить/починить запрос», выключает после. Причина изоляции одна и
  она не про вкус: **этот путь физически невозможно загейтить `BudgetStore`**, поэтому он не должен
  быть достижим из автономного цикла.
- **Слой C — каталог. Файл-реестр в репозитории.** Замена несуществующего шага «найти чужой
  запрос»: программного поиска чужой аналитики в API **нет как класса** — в официальном MCP тула
  поиска нет, в OpenAPI 39 путей и единственный search (`POST /v1/datasets/search`) ищет **таблицы**,
  а `GET /v1/queries` возвращает **свои** запросы.

## Риск-лог: что должно быть решено до первого рубля

1. **Доступ к API на Free противоречив в самом первоисточнике** — `pricing-faqs.md:254` против
   `:135`. Разрешается **только** T0.
2. **Analyst или Plus для Query-эндпоинтов** — из первоисточника не выводится (3 страницы против 1).
   На практический вывод не влияет (на Free не работает ни то, ни другое), на смету апгрейда — да.
3. **Собственные лимиты `/mcp/v1`** (rate limit, размер ответа, серверный таймаут) вендором не
   задекларированы — `unverified`. Единственное документированное ограничение чужое и клиентское:
   таймаут MCP-клиента 60 с, обход — `tool_timeout_sec = 300`.
4. **Цена конкретного исполнения непредсказуема по определению вендора** — дословно: «we don't share
   a single, per-query formula because credit usage depends on real-time factors». Поэтому
   `costObserved` заполняется только замером, а `reserveCredits` ставит человек и защищает
   `checkAndReserve`.
5. **Свежесть на Free не контролируется вообще.** «The Free query engine is limited to manual query
   editor executions only; automated executions (API, scheduling, refreshing) are not available».
   Протухший результат чужого запроса **нельзя обновить через API ни за какие кредиты** — свежесть
   целиком во власти владельца запроса. Это ограничение продукта, а не нашей реализации, и оно
   должно быть явно отражено в контракте тула (`staleAsOf` в ответе).
6. **Лицензия Blockscout** (A-2) — юридический вопрос, не инженерный.
