# WI-22 — задачник `dune-tasks.md` опровергнут живым зондом дважды подряд; A-4 идёт из него же

`docs/dune-query-discovery/dune-tasks.md` — источник трека A (A-1…A-4). **Два его утверждения уже
опровергнуты живыми зондами, по одному на каждую задачу, которая им пользовалась:**

| задача         | что сказано в файле                                                          | что измерил зонд                                                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TASK-008 (A-2) | «битый ключ отдаёт 401 **без** отката на серверный — проверено живьём»       | Фасад вернул **HTTP 200** на заведомо мусорный ключ; аутентификация не принуждалась вовсе. 401 принадлежит **другому хосту**, не тому, который файл предписывает вызывать                                                   |
| TASK-009 (A-3) | «`blockchain.info/q/*` — keyless, "одно число одним вызовом" **для эмиссии**» | `/q/totalbc` — **не** эмиссия. Значение отстоит от границы халвинга на **дробное** число субсидий, то есть формулой быть не может; это реально заявленное предложение, на ~29–32 BTC меньше. Формула — это `/stats.totalbc` |

У обеих ошибок одна форма: файл называет настоящий эндпоинт и описывает его **почти** верно, а разница
достаточно мала, чтобы пережить ревью. Ошибка A-3 отдала бы число под чужим именем с погрешностью
**0.00016%** — ни человек, ни модель ниже по течению этого не поймали бы.

**Это не дефект файла.** Он писался по исследовательскому отчёту, сам отчёт об этом говорит, а
рабочая дисциплина в `CLAUDE.md` уже требует пробовать вендорские факты живьём. Запись существует
потому, что **A-4 из этого же источника ещё не выполнена**, а три её утверждения про адаптер `dune`
— ровно того класса, который ошибся уже дважды.

**Что делать тому, кто возьмёт A-4:** зондировать до проектирования и записывать дельту в собственный
§1.1 задачи, как сделали TASK-008 и TASK-009. Ссылки вида `файл:строка` в задачнике тоже не считать
текущими — они были верны на момент написания, а файлы с тех пор двигались.

**Evidence:** `docs/onchain-analytics/raw/btc-crosscheck-plaintext-2026-07-29.json` (запиннен в
`provenance.json`) — дробность `/q/totalbc` как доказательство, а не наблюдение.

## Закрыто 2026-07-30 — предупреждение живёт в самом задачнике, а не только здесь

Запись создавалась ради одного: чтобы тот, кто возьмёт A-4, узнал об этом **до** проектирования.
Бэклог для этого — неверное место: A-4 читают из `dune-tasks.md`, а не отсюда. Поэтому
актуализирован сам источник:

- **опровергнутое утверждение зачёркнуто на месте** (`~~/q/* — одно число одним вызовом для
  эмиссии~~`) с указанием, где лежит формульная величина. Не переписано молча: ошибка задачника —
  сама по себе факт, важный для A-4;
- **блок «✅ ВЫПОЛНЕНО» для A-3** по образцу A-1: четыре факта зонда, включая тавтологичность сверки
  supply с формулой и запрет мерить дельту в процентах;
- **предупреждение прямо над разделом A-4** — таблица обеих ошибок (A-2 про 401, A-3 про `/q/*`) с
  общей формой: назван настоящий эндпоинт и описан *почти* верно. Там же сказано, что ссылки
  `файл:строка` в A-4 устарели — `token.holders` уехал на `blockscout`, поэтому первый и третий
  пункты A-4 надо перечитать заново, а не выполнять по тексту;
- **строки статуса и таблица прогресса** в шапке и в «Порядке исполнения»: A-1/A-2/A-3 ✅, A-4 ⬜.

Запись закрыта, но **сам риск не закрыт и не может быть**: он снимется только когда A-4 будет
выполнена с живым зондом. Здесь закрыт долг «предупреждение существует там, где его прочитают».
